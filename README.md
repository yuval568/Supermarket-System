# 🛒 Supermarket ERP System - Inventory & HR Modules

[![Java](https://img.shields.io/badge/Java-Core-ED8B00?style=flat-square&logo=openjdk&logoColor=white)](#) [![SQLite](https://img.shields.io/badge/Database-SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white)](https://www.sqlite.org/) [![Architecture](https://img.shields.io/badge/Architecture-Modular%20%7C%20GRASP-6f42c1?style=flat-square)](#) [![CLI](https://img.shields.io/badge/Interface-CLI%20Console-4D4D4D?style=flat-square&logo=gnu-bash&logoColor=white)](#) [![Testing](https://img.shields.io/badge/Testing-JUnit%205-25A162?style=flat-square&logo=junit5&logoColor=white)](#)

- 📦 **Inventory & Stock Management Module:** Full tracking of products, categories, stock deficits, minimum thresholds, and automatic order triggers.
- 👥 **HR & Employee Scheduling Module:** Complete management of employee details, role permissions, and shift-availability scheduling.
- 🔌 **Mock Integration Architecture:** Utilizes Mock/Stub interfaces for Suppliers and Logistics modules to support seamless future integration with low coupling.
- 💾 **Unified Persistence Layer:** Single SQLite relational database for robust data management and transaction logging across active modules.
- 🛠️ **Tech Stack & QA:** Java, SQLite, CLI Interface, Maven build (`ads2025_v02.jar`), and JUnit 5 unit/integration testing suite.
